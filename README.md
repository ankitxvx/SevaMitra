# 🏛️ SevaMitraAI (सेवामित्र)
### *Speech-First, Multilingual, Channel-Agnostic Platform for Revenue Department Citizen Services*

SevaMitraAI is an intelligent, voice-first citizen assistance platform engineered to guide users of all literacy levels through complex government revenue certificate procedures (Income, Caste, Domicile, Solvency, Nativity, etc.). It turns natural spoken conversation into validated, structured government application forms, orchestrates document verification and fee payment, preserves context across channels, supports corrections, and exposes an operational telemetry dashboard.

---

## 🌟 Key Features

- **🎙️ Speech-First Voice Agent**: Full-screen interactive voice orb with live audio frequency wave visualization and hands-free conversation.
- **🔊 Real-Time Voice Narration (TTS)**: Every question generated by the AI is automatically read out loud in clear spoken audio.
- **🌐 Multilingual Support**: Speak or type in Hindi (हिंदी), English, Marathi (मराठी), Tamil (தமிழ்), Telugu (తెలుగు), Bengali (বাংলা), Gujarati (ગુજરાતી), and regional dialects.
- **📋 Structured Form Preview & Editing**: Automatically transforms conversational Q&A into official Revenue Department application formats with inline field correction.
- **🗂️ "My Filled Forms" History**: View and track all past submitted forms and certificates in one place.
- **📄 Document Capture & AI Verification**: Upload ID proofs (Aadhaar, Voter ID, PAN) with simulated OCR validation.
- **💳 Simulated Payment Gateway**: Complete statutory e-District processing fee payments with receipt generation.
- **📍 Real-Time Status Tracking**: Instant status lookup using departmental Tracking IDs (e.g. `TRK-A1B2C3D4`).
- **📊 Operational Telemetry Dashboard**: Live metrics tracking total forms, completion rates, pending stages, and revenue.

## ⚙️ Prerequisites

Before running the project locally, ensure you have:
1. **Python 3.10+** installed ([Download Python](https://www.python.org/downloads/))
2. **Node.js 18+** & npm installed ([Download Node.js](https://nodejs.org/))
3. **FFmpeg** installed (required for Whisper audio processing):
   - **Windows**: `winget install ffmpeg`
   - **macOS**: `brew install ffmpeg`
   - **Linux**: `sudo apt install ffmpeg`

## 🚀 Step-by-Step Local Setup & Execution

### 1. Clone the Repository
```bash
git clone https://github.com/ankitxvx/SevaMitraAI.git
cd SevaMitraAI
```

---

### 2. Backend Setup (FastAPI & AI Services)

Open a terminal in the `SevaMitraAI` root directory:

```powershell
# 1. (Optional) Create & activate a virtual environment
python -m venv venv
.\venv\Scripts\activate      # On Linux/macOS: source venv/bin/activate

# 2. Install Python dependencies
pip install -r backend/requirements.txt

# 3. Set Python path
$env:PYTHONPATH = "."        # On Linux/macOS: export PYTHONPATH="."

# 4. Start the FastAPI backend server
python -m uvicorn backend.main:app --reload --port 8000
```
> Backend will be running live at: `http://localhost:8000` (API Docs: `http://localhost:8000/docs`)

---

### 3. Frontend Setup (React + Vite)

Open a **new terminal** window:

```bash
# 1. Navigate to the frontend directory
cd frontend

# 2. Install Node.js dependencies
npm install

# 3. Start the Vite development server
npm run dev
```
> Frontend will be running live at: `http://localhost:5173`

## 📖 How to Use the Application

1. **Launch the Web App**: Open your browser at `http://localhost:5173`.
2. **Citizen Authentication**: Click **"Citizen Sign In"** in the sidebar to log in via mobile OTP (Demo mode accepts any 4 digits).
3. **Start an Application**:
   - Choose a preset service (*Income, Caste, Domicile, Solvency*) or simply speak/type what you need.
   - Tap the **Voice Orb** or hold the mic button to answer questions in Hindi or English.
4. **Structured Form Confirmation**:
   - Once all questions are answered, review the generated form summary on screen.
   - Click **"Edit / Review Form"** to open the full official document preview and correct any typos.
5. **Document Capture & Verification**:
   - Upload supporting documents (Aadhaar / Voter ID) for automated validation.
6. **Payment & Receipt**:
   - Pay the simulated ₹150 processing fee and receive your unique **Tracking ID**.
7. **Track Application**:
   - Go to **Track Status** and enter your Tracking ID to view real-time approval status.
8. **Operational Dashboard**:
   - Visit the **Dashboard** to view live system analytics, application throughput, and revenue.

## 📡 API Endpoints Reference

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/session` | Create a new stateless citizen application session |
| `GET` | `/api/session/{id}` | Fetch current state, form fields & captured answers |
| `POST` | `/api/select-form` | Select revenue service & trigger LLM question generation |
| `POST` | `/api/process-audio` | Ingest audio speech, transcribe with Whisper & advance state |
| `POST` | `/api/process-text` | Ingest text response & advance form state |
| `POST` | `/api/update-response`| Inline field correction on structured form |
| `GET` | `/api/applications` | Retrieve all citizen application histories |
| `POST` | `/api/upload-document`| Upload supporting documents with mock OCR validation |
| `POST` | `/api/pay` | Process payment & issue official Tracking ID |
| `GET` | `/api/track-status/{tid}`| Check real-time departmental application status |
| `GET` | `/api/dashboard/stats` | Telemetry metrics for operational dashboard |
